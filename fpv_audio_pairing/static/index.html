07 /Aligned exportsShared interval · original frame rates by default

Export the common interval from each confirmed pair. Put the two exported clips at the same point in DaVinci Resolve or another editor.

Trim the common interval
For all pairs, leave the end blank to use each pair's full overlap.

Choose a folder on the machine running Flight Sync, or type a new folder path. Each export creates a readable session folder here; a single pair’s clips sit directly inside it. Leave blank for the default. Use Download ZIP to save on the PC viewing the app.

Fast trim copies original video/audio and preserves frame cadence. Cuts between keyframes require an editor that honors MP4 edit lists; choose Accurate trim for compatibility.
