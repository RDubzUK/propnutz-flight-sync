# Branding assets

PropNutz Flight Sync is an associated PropNutz tool, branded at the site owner's request.

- `warehouse.jpg`: https://www.propnutz.co.uk/public/external/propnutz-graffiti-wall.jpg
- `favicon.png`: https://www.propnutz.co.uk/public/external/image19205-pcgr-200h.png
- Palette and wordmark treatment: https://www.propnutz.co.uk/street.css
- `fonts.css` / `font-*.woff2`: locally hosted Latin subsets of Barlow (400/500/600/700) and Barlow Condensed (600/700/800/900), downloaded from Google Fonts.
- `Barlow-OFL.txt`, `BarlowCondensed-OFL.txt`: original SIL Open Font License files from https://github.com/google/fonts/tree/main/ofl.

Assets retrieved 2026-10-06. No third-party font or image request is required at runtime. Existing matching, session, source and export behavior is unchanged by the branding.
